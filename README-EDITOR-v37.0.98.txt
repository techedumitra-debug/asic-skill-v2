ASIC-Skill v37.0.98 – Lesson titles and original content editing

NEW
• Rename Lesson Page changes the visible lesson heading, sidebar label, and lesson-selection option together. Stable lesson IDs are preserved so bookmarks continue to work.
• Existing and newly inserted content blocks (original tables, images, notes, figures, diagrams, text and grouped subsections) can be moved using the context Drag Block handle, Move Up / Move Down controls, or deleted with confirmation.
• Context toolbar is placed OUTSIDE of tables and figures to avoid invalid HTML structure and table-column reordering.
• Saved drafts from v37.0.97 remain available. Exporting and reopening preserves renamed lessons and new block order.

HOW TO USE
1. Open a unit and click Edit Content.
2. Rename page: choose its name in Lesson pages, then click Rename Lesson Page, OR edit the large title directly.
3. Move built-in content: click a table, image, diagram or other block. Use the small Drag Block toolbar above it, or Move Up / Down from the editor.
4. Delete built-in content: click the block; choose Delete Content Block. Undo Last Delete works before export.
5. Export Updated HTML and replace that particular unit HTML file in your GitHub repository.

IMPORTANT
• The editor works locally in your browser; no public viewer can change the hosted repository.
• Interactive widgets may depend on surrounding markup or fixed element IDs. Moving or deleting those is permitted, but check them before publishing.
• Move Up/Down works within a content section. Dragging can move into another content subsection of the same lesson.
• Backup any customized pages before publishing.
