ASIC-Skill v37.1.03 — HTML LESSON IMPORT AND LESSON PLAN ORDER

Open any Digital Electronics unit (content-editor.html → unit) and click Edit Content.

NEW: Add HTML File as Lesson: pick a local .html/.htm file and the editor extracts the lesson content into the unit. It becomes a separate navigable lesson in the unit and is bundled with the exported unit HTML. Imported inline scripts and styles are intentionally removed; external images/assets require valid relative paths in the same website. The source file itself is not separately published.

NEW: Blank Lesson: create an empty lesson page for authoring.

NEW: Link Separate HTML Page: give a lesson title and a relative .html path (e.g. custom-lesson.html). This adds a separate link in the lesson content list. The linked HTML must separately exist in the published website folder; this browser-only editor does not write or upload the external file.

NEW: Lesson plan: select any lesson or external HTML link and use Earlier, Later, or Move to Position. The sidebar and Next/Previous navigation follow this order. The change persists in a local draft and the exported HTML.

Export ALL Lessons HTML → replace the unit's original HTML file in your website and upload any separately linked HTML files too. Back up before overwriting.

Imported HTML safety: scripts, styles, forms and embedded external web content are removed intentionally. Complex interactive HTML may need manual assets / scripts integrated separately.

Version 37.1.03 is based on uploaded v37.1.02.
