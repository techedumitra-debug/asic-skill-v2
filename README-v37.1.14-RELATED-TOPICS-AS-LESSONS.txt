ASIC-Skill v37.1.14 — Related Topics as Standalone Lessons

Based on the supplied ASIC-Skill v37.1.13 complete website.

Change:
- Every embedded "RELATED TOPIC" (previously an article.de-sublesson) is now a
  separate section.de-lesson immediately following its source lesson.
- Each related topic has a sidebar entry, its own heading, Previous/Next buttons,
  completion toggle, and hash navigation target.
- Original related-topic content and inline diagrams, tables, interactive tools,
  media, and JavaScript are retained. The content-editor can edit the new lesson.
- Static navigation indexes and initial progress counts are updated for every unit.
- Original parent lesson IDs and related-topic IDs remain unchanged, to retain
  bookmarks wherever possible.

Usage: Open digital-electronics.html with VS Code Live Server. Use the sidebar
or Next Lesson to reach the Related Topic page after its parent lesson. Use Edit
Content and Export ALL Lessons HTML to publish further changes.

Caution: Back up the current website and any browser-only drafts before using
this update. This package was generated from the uploaded v37.1.13 ZIP and
cannot contain unpublished draft changes kept only in Chrome Local Storage.
