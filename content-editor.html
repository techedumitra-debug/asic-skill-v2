Visual Content Studio · Office-style Editor · Font-Size Controls & Full Lesson Export

Choose a unit to edit its lesson descriptions, tables, images and lesson pages directly in the webpage. This authoring tool works without a server and requires no login, but it cannot directly publish changes to GitHub.

How to publish changes
  1. Open a unit below and click existing text to edit it.
  2. Click the sentence or heading where new content should appear, then choose + Heading, + Paragraph, + Note, + List or + Image. New items are inserted directly after your selection.
  3. Rearrange both existing and new sections with the ⠿ Drag handle, or use ↑ Up / ↓ Down and To Top / To Bottom.
  4. Use the Word-style toolbar for fonts, numeric font sizes, A− / A+ buttons, bold/italic/underline, colors, alignment and lists. Select text for character-level changes, or click a paragraph/table cell to resize the whole element. Select a table cell to add or remove rows and columns. Use Rename Image / Caption to change image labels. Drag the editor by its title bar. Use Save Draft for local work, and Preview to view the result.
  5. To rename a lesson, choose it under Lesson pages, click Rename Lesson Page, and enter its new name; the page heading and sidebar will both update. To add a lesson page, use Add HTML File as Lesson in the editor, or use Link Separate HTML Page to link an independently hosted file. Reorder any lesson using Earlier/Later or Move to Position; the exported lesson content list will use the new order. For a complete lesson removal, choose its title under Lesson pages, click Delete Lesson Page, confirm and export. The lesson and sidebar item are removed from the HTML. Click Restore Lesson before exporting if you change your mind. Then click Export Updated HTML, replace the same-named file in GitHub and commit it.

Font size: click any heading, paragraph, list item or table cell, choose a size (7–96 pt), or use A− / A+ to decrease/increase the font by 1 point. Highlight text first to resize only the selection. The font size is preserved in exported HTML. The floating editor can be dragged or resized. The Export ALL Lessons HTML control includes changes to every lesson in the selected unit, even lessons hidden behind the Previous/Next buttons. To resize a table, click a cell, then set Table width (%) and Selected column width (%). Delete old or new blocks; select a table cell for text or row/column changes; rename or replace uploaded images. Advanced HTML source mode can edit SVG, CSS and scripts, but changes to widget logic should be tested carefully. Table column order is never automatically changed. Drafts from older HTML revisions are not automatically applied to a newly exported webpage; click Restore Prior Draft only when you intentionally want the older edits. Local drafts remain only in your browser; GitHub publishing still requires replacing exported HTML.
