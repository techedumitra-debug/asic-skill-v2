2.1 · Decimal Number System: Understanding Base-10 and Positional Place Values

The decimal number system is a base-10 positional number system that uses ten digits, ranging from 0 to 9, to represent numerical values. It is the most commonly used number system in everyday calculations, measurements, and mathematical operations.

  • In a positional number system, the value of each digit depends on both its numerical value and its position within the number. Each position carries a specific place value (positional weight) determined by a power of the base, which is 10 in the decimal system.
    • For digits located to the left of the decimal point, the positional weights increase as powers of 10: 10⁰, 10¹, 10², 10³, and so on, moving from right to left.
    • For digits located to the right of the decimal point, the positional weights decrease as negative powers of 10: 10⁻¹, 10⁻², 10⁻³, and so on, moving from left to right.

= 253.47

2.1.2 · Subtraction Using the 9's Complement Method

Subtraction using the 9's complement is a mathematical technique that allows decimal subtraction to be performed through addition. Instead of directly subtracting one number from another, the 9's complement of the subtrahend is added to the minuend, and the result is adjusted based on whether an end carry is generated.

  • This method is particularly useful for understanding complement arithmetic, which forms an important foundation for arithmetic operations in digital electronic systems.

Steps for Subtraction Using 9's Complement:

To subtract two decimal numbers using the 9's complement method:

  1. Equalize the number of digits: Add leading zeros where necessary so that both numbers have the same number of digits.

  2. Find the 9's complement: Subtract each digit of the subtrahend from 9.

  3. Perform addition: Add the 9's complement to the minuend.

  4. Check for an end carry:

    • If an end carry is generated: Add the carry to the remaining result. This is called end-around carry.

    • If no end carry is generated: Take the 9's complement of the obtained result and place a negative sign before it.

Example: Subtraction with a Positive Result

Problem: Calculate 725 − 253 using 9's complement.

Step 1: Find the 9's complement of 253.

9's complement = 999 − 253 = 746

Step 2: Add the complement to 725.

Step 3: Apply the end-around carry.

An end carry of 1 is generated. Remove this carry and add it to the remaining three-digit result.

Final Answer: 725 − 253 = 472

Problem: Calculate 253 − 725 using 9's complement.

Step 1: Find the 9's complement of 725.

9's complement = 999 − 725 = 274

Step 2: Add the complement to 253.

Step 3: Check for an end carry.

No end carry is generated, indicating that the result is negative.

Step 4: Find the 9's complement of 527.

Attach a negative sign to the obtained magnitude.

Final Answer: 253 − 725 = −472

2.1.3 · Subtraction Using the 10's Complement Method

Subtraction using the 10's complement is an arithmetic technique that simplifies decimal subtraction by converting it into an addition operation. Instead of directly subtracting one number from another, the 10's complement of the subtrahend is added to the minuend. The final result is determined by checking whether an end carry is generated.

  • This method is particularly important in digital electronics because it demonstrates how arithmetic circuits can perform subtraction through addition, a principle also used in binary arithmetic with 2's complement representation.

Understanding the 10's Complement:

  • The 10's complement of an n-digit decimal number is obtained by subtracting the number from 10ⁿ.
  • Formula: 10's Complement = 10ⁿ − N
    • Where: N: Original decimal number ; n: Number of decimal digits
Alternatively, the 10's complement can be calculated by adding 1 to the 9's complement.
  • Example: Find the 10's complement of 253.
    • 10's Complement = 1000 − 253 = 747

Steps for Subtraction Using 10's Complement

  1. Equalize the number of digits: Add leading zeros where necessary so that both numbers have the same number of digits.

  2. Calculate the 10's complement: Find the 10's complement of the number being subtracted (subtrahend).

  3. Perform addition: Add the complement to the original number (minuend).

  4. Check for an end carry:

    • If an end carry is generated: Discard the carry beyond the fixed digit width. The remaining digits represent the nonnegative result.

    • If no end carry is generated: Take the 10's complement of the obtained result and attach a negative sign.

Step 1: Find the 10's complement of 253.

10's Complement = 1000 − 253 = 747

Step 2: Add the complement to the minuend.

725 + 747 = 1472

Step 3: Discard the end carry.

Since the calculation uses three decimal digits, discard the leading carry of 1.

Remaining result = 472

Final Answer: 725 − 253 = 472

Step 1: Find the 10's complement of 725.

10's Complement = 1000 − 725 = 275

Step 2: Add the complement to the minuend.

No end carry is generated, indicating that the result is negative.

2.2 · The Binary Number System: Understanding Base-2 Representation in Digital Electronics

The binary number system is a base-2 positional number system that uses only two digits, 0 and 1, to represent numerical values. It forms the foundation of digital electronics and computing systems because digital circuits operate using two distinct logical states, commonly represented as LOW (0) and HIGH (1).
  • Each binary digit is called a bit, and its numerical value depends on its position within the binary number. Unlike the decimal number system, which uses powers of 10, the binary number system assigns powers of 2 to each digit position.

    • For digits located to the left of the binary point, the positional weights increase as 2⁰, 2¹, 2², 2³, and so on, moving from right to left.

    • For digits located to the right of the binary point, the positional weights decrease as 2⁻¹, 2⁻², 2⁻³, and so on, moving from left to right.

Understanding Binary Place Values:

Consider the binary number 1011.101₂.

Its expanded representation is:

1011.101₂ = (1 × 2³) + (0 × 2²) + (1 × 2¹) + (1 × 2⁰) + (1 × 2⁻¹) + (0 × 2⁻²) + (1 × 2⁻³)

= 8 + 0 + 2 + 1 + 0.5 + 0 + 0.125

= 11.625₁₀

Therefore, the binary number 1011.101₂ is equivalent to the decimal number 11.625₁₀.

2.2.1 · Counting in Binary: Understanding Number Sequences and Carry Operations in Base-2

Binary counting is the process of representing consecutive numerical values using only two digits, 0 and 1. Unlike the decimal number system, which uses ten digits (0–9), the binary number system follows a base-2 counting sequence, where each digit position represents a power of 2.

In binary counting, the rightmost bit is called the Least Significant Bit (LSB), while the leftmost bit is called the Most Significant Bit (MSB). Counting begins at zero, and each successive number is obtained by adding binary 1 to the previous value.

When a binary digit changes from 0 to 1, no carry is generated. However, when a binary digit changes from 1 to 0 during an increment, a carry is propagated to the next higher bit position.

Understanding Carry Operations in Binary Counting

In binary arithmetic, each bit can represent only 0 or 1. When adding 1 to a bit that is already 1, the result produces 0 with a carry of 1 to the next higher position.

This demonstrates how carry propagation enables binary numbers to increase beyond the value represented by a single bit.

Binary Counting Using Digital Counters:

In digital electronics, binary counting is commonly implemented using sequential circuits called binary counters.

A binary counter typically consists of flip-flops that store the current count and update their states in response to clock pulses.

For example, a 4-bit binary up counter follows the counting sequence:

0000 → 0001 → 0010 → 0011 → ... → 1110 → 1111 → 0000

Since a 4-bit counter can represent 16 different states (2⁴ = 16), it counts from decimal 0 to 15 before returning to zero.

This behavior is known as modulo-16 counting.

Practical Applications of Binary Counting

Binary counters are widely used in digital systems for:

  • Digital Clocks and Timers: Counting clock pulses to measure time intervals.

  • Frequency Division: Generating lower-frequency signals from a high-frequency clock.

  • Event Counting: Recording the number of pulses or external events.

  • Memory Address Generation: Producing sequential binary addresses.

  • Control Systems: Tracking operating sequences and coordinating digital operations.

Key Takeaway:

Binary counting represents consecutive numbers using combinations of 0 and 1, with carry propagation occurring whenever a bit exceeds its maximum value. Understanding binary counting is essential for learning binary arithmetic, flip-flops, counters, frequency dividers, and sequential digital circuit design.

2.2.2 · Binary-to-Decimal Conversion: Understanding Positional Weights and Powers of Two

Binary-to-decimal conversion is the process of converting a number from the binary number system (base-2) into its equivalent value in the decimal number system (base-10).

  • The binary number system uses only two digits, 0 and 1, whereas the decimal number system uses ten digits, 0 through 9.
  • In binary representation, each digit has a specific positional weight determined by a power of 2. To convert a binary number into decimal, multiply each binary digit by its corresponding positional weight and add the resulting values.

Steps for Binary-to-Decimal Conversion:

  1. Identify the binary digits: Write the given binary number and identify each bit position.

  2. Assign positional weights: Starting from the rightmost bit, assign powers of 2 as 2⁰, 2¹, 2², 2³, and so on.

  3. Multiply each bit by its weight: Multiply every binary digit (0 or 1) by the corresponding power of 2.

  4. Add the results: Sum all the calculated values to obtain the equivalent decimal number.

2.2.3 · Decimal-to-Binary Conversion: Converting Base-10 Numbers into Binary Representation

Decimal-to-binary conversion is the process of converting a number from the decimal number system (base-10) into its equivalent representation in the binary number system (base-2).

The decimal number system uses ten digits (0–9), while the binary number system uses only two digits, 0 and 1. Since digital electronic circuits process information using binary logic states, decimal-to-binary conversion is essential for representing numerical values in computers, microprocessors, and digital systems.

Decimal-to-binary conversion can be performed using two fundamental methods:

  • Repeated Division by 2: Used to convert the integer part of a decimal number into binary.

  • Repeated Multiplication by 2: Used to convert the fractional part of a decimal number into binary.

Converting Decimal Integers into Binary:

The repeated division-by-2 method converts a decimal integer into its binary equivalent by successively dividing the number by 2 and recording the remainder obtained at each step.

Conversion Steps:

  1. Divide the decimal number by 2.

  2. Record the remainder, which will be either 0 or 1.

  3. Divide the resulting integer quotient by 2.

  4. Repeat the process until the quotient becomes zero.

  5. Read the recorded remainders from bottom to top to obtain the binary equivalent.

Converting Decimal Fractions into Binary:

The repeated multiplication-by-2 method is used to convert the fractional part of a decimal number into its binary equivalent.

In this method, the fractional value is repeatedly multiplied by 2, and the integer part obtained after each multiplication becomes the next binary digit.

Conversion Steps:

  1. Multiply the decimal fraction by 2.

  2. Record the integer part of the result (0 or 1).

  3. Use the remaining fractional part for the next multiplication.

  4. Repeat until the fractional part becomes zero or the required precision is reached.

  5. Read the recorded integer digits from top to bottom to obtain the binary fraction.

Important Considerations in Decimal-to-Binary Conversion:

  • Integer Conversion: Repeated division by 2 produces binary digits starting from the Least Significant Bit (LSB). Therefore, remainders must be read in reverse order.
  • Fractional Conversion: Repeated multiplication by 2 produces binary digits starting from the first fractional position (2⁻¹). Therefore, the recorded integer parts must be read in their original order.
  • Binary Precision: Not every decimal fraction has an exact finite binary representation. For example, decimal 0.1 produces a repeating binary fraction and requires rounding when stored using a limited number of bits.
  • Fixed Bit Width: Digital circuits use a predefined number of bits to represent values. For example, an unsigned 8-bit binary number can represent decimal values from 0 to 255.

Applications in Digital Electronics:

Decimal-to-binary conversion is widely used in:

  • Digital Arithmetic: Representing numerical operands for binary calculations.

  • Microprocessors and Microcontrollers: Encoding numerical data for processing and storage.

  • Memory Systems: Representing stored numerical values and memory addresses.

  • Analog-to-Digital Conversion: Interpreting quantized measurements as binary values.

  • Hardware Design and Verification: Representing and testing binary values in Verilog and VHDL.

2.2.3 · Fractional Radix Conversion: Converting Fractional Numbers Between Different Number Systems

Fractional radix conversion is the process of converting the fractional part of a number from one number system into an equivalent representation in another number system, such as decimal (base-10), binary (base-2), octal (base-8), or hexadecimal (base-16).

  • In a positional number system, each digit to the right of the radix point represents a negative power of the number system's base. For example, decimal fractions use positional weights of 10⁻¹, 10⁻², 10⁻³, while binary fractions use 2⁻¹, 2⁻², 2⁻³.
  • Understanding fractional radix conversion is essential for representing numerical values, performing digital arithmetic, and interpreting fixed-point and floating-point data in digital electronic systems.

2.2.5 · Binary Subtraction: Understanding Borrow Operations and Complement Arithmetic in Base-2

Binary subtraction is a fundamental arithmetic operation used in digital electronics to calculate the difference between two binary numbers. Unlike decimal subtraction, which operates with ten digits (0–9), binary subtraction uses only two digits: 0 and 1.

  • Binary subtraction follows principles similar to decimal subtraction, but borrowing occurs in base-2 arithmetic. When a smaller bit value must subtract a larger bit value, a borrow is taken from the next higher bit position.
  • This operation forms the foundation of digital arithmetic circuits, including half subtractors, full subtractors, binary subtractors, Arithmetic Logic Units (ALUs), and microprocessors.

Basic Rules of Binary Subtraction:

Binary subtraction follows four fundamental rules:

Binary OperationDifference BitBorrow Required

1 − 01No
1 − 10No
0 − 11Yes

When subtracting binary 1 from binary 0, a borrow is required from the next higher bit position.

Example:

0 − 1 = 1 with a borrow of 1

In binary arithmetic, borrowing 1 from the next higher position adds a value of 2 to the current bit position.

Therefore:

(0 + 2) − 1 = 1

The borrowed value reduces the next higher bit position by 1.

Understanding Borrow Operations in Binary Subtraction:

  • When subtracting multi-bit binary numbers, each bit position is processed from right to left, beginning with the Least Significant Bit (LSB).
  • If the bit being subtracted is greater than the available value in the current column, a borrow is taken from the next higher position.
  • Sometimes the next higher bit is also 0. In such cases, borrowing must continue through successive bit positions until a 1 is encountered. This process is known as borrow propagation.

  4. Bit 3: 1 − 0 = 1.

  3. Bit 2: Similarly, this column retains an effective value of 1 after passing the borrow. The difference bit is 1.

2.2.7 · Sequential Shift-and-Add Multiplication: Understanding Binary Multiplication Using Registers, Shifting, and Addition

Sequential shift-and-add multiplication is a digital arithmetic technique used to multiply two binary numbers by performing a series of conditional additions and bit-shifting operations over multiple clock cycles.

Unlike a combinational multiplier, which calculates the product through a network of logic gates without requiring multiple clock cycles, a sequential multiplier performs multiplication step by step using reusable hardware components such as registers, a binary adder, shift circuits, and a control unit.

  • This approach can reduce hardware complexity and circuit area, making it useful in microcontrollers, embedded systems, and resource-constrained digital designs where minimizing hardware is more important than completing multiplication in a single clock cycle.

Basic Principle of Sequential Shift-and-Add Multiplication:

Sequential multiplication is based on the mathematical principle that a binary number can be expressed as the sum of powers of 2.

Each bit of the multiplier determines whether a shifted copy of the multiplicand should be added to the accumulated result.

The multiplication process involves three fundamental operations:

  1. Examine the Multiplier Bit: Check the Least Significant Bit (LSB) of the multiplier.

  2. Perform Conditional Addition: If the multiplier bit is 1, add the current multiplicand value to the accumulated partial product. If the bit is 0, skip the addition.

  3. Perform Bit Shifting: Shift the multiplicand one position to the left and the multiplier one position to the right, preparing both operands for the next cycle.

The process repeats until all multiplier bits have been examined.

Key Concept: A left shift multiplies an unsigned binary value by 2, provided sufficient bit width is available, while a logical right shift divides an unsigned binary value by 2 and discards the remainder.

Hardware Components of a Sequential Multiplier:

A basic sequential shift-and-add multiplier contains the following functional blocks:

Hardware ComponentPrimary Function
Multiplicand Register (M)Stores the multiplicand and shifts its value left during multiplication.
Multiplier Register (Q)Stores the multiplier and shifts its value right to examine each successive bit.
Accumulator Register (P)Stores the intermediate partial products and final multiplication result.
Binary AdderAdds the shifted multiplicand to the accumulated partial product when required.
Control UnitCoordinates addition, shifting, register updates, and completion of the multiplication.
Clock SignalSynchronizes the operations performed during each multiplication cycle.

Simplified Signal Flow:

Multiplier LSB (Q₀) → Control Unit → Addition Enable

Multiplicand Register (M) + Accumulator (P) → Binary Adder → Updated Accumulator (P)

After each cycle, the multiplicand shifts left and the multiplier shifts right.

Step-by-Step Multiplication Algorithm:

Consider multiplying two unsigned n-bit binary numbers.

Initialization:

  • Load the multiplicand into register M, extended to 2n bits.
  • Load the multiplier into register Q.
  • Clear the 2n-bit accumulator P to zero.
  • Initialize the cycle counter to n.

Repeated Operations:

Step 1: Examine the LSB of multiplier Q.

Step 2: If Q₀ = 1, calculate P = P + M.

Step 3: If Q₀ = 0, retain the existing accumulator value.

Step 4: Shift M one position to the left.

Step 5: Shift Q one position to the right.

Step 6: Decrement the cycle counter.

Step 7: Repeat until n multiplier bits have been processed.

After all cycles are completed, the accumulator contains the final unsigned multiplication result.

7. Mathematical Explanation

The multiplier can be expressed as the sum of its positional weights.

0101₂ = (0 × 2³) + (1 × 2²) + (0 × 2¹) + (1 × 2⁰)

Therefore:

0101₂ = 4 + 1 = 5

The multiplication operation becomes:

11 × 5 = (11 × 4) + (11 × 1)

In binary:

1011₂ × 0101₂ = (1011₂ << 2) + 1011₂

Here, << 2 represents shifting the binary value two positions to the left.

The shifted partial products are:

  • 1011₂ × 1 = 00001011₂

  • 1011₂ × 4 = 00101100₂

Adding the partial products:

00001011₂ + 00101100₂ = 00110111₂

Thus, multiplication is achieved through conditional addition and bit shifting, rather than requiring a separate multiplication operation at each step.

Timing and Design Considerations:

Sequential multiplication requires careful coordination between the clock, control unit, adder, and storage registers.

  • Clock Synchronization: Register updates occur at defined clock events, ensuring that the accumulated result and shifted operands progress through the correct multiplication sequence.
  • Register Width: For an unsigned n-bit by n-bit multiplication, a 2n-bit product register is sufficient to store the complete result.
  • Addition Delay: The binary adder must complete its calculation within the available register-to-register timing budget.
  • Cycle Count: The simple algorithm requires n processing cycles for an n-bit multiplier. Additional cycles may be required for loading operands or reporting completion, depending on the architecture.
  • Signed Numbers: This example uses unsigned operands. Signed multiplication requires suitable sign handling, such as sign extension or a signed multiplication algorithm.

Applications of Sequential Shift-and-Add Multiplication:

Sequential multipliers are used in:

  • Microcontrollers: Performing multiplication with limited arithmetic hardware.

  • Embedded Systems: Reducing hardware area in low-cost digital designs.

  • Digital Signal Processing: Implementing arithmetic operations where low hardware cost is important.

  • FPGA Design: Building resource-efficient multiplication circuits using registers and adders.

  • ASIC and VLSI Design: Exploring trade-offs between circuit area, latency, throughput, and power consumption.

  • Educational Processor Design: Demonstrating how arithmetic operations are implemented through datapath and control logic.

Sequential shift-and-add multiplication performs binary multiplication by examining multiplier bits one at a time, conditionally adding shifted multiplicand values, and storing intermediate results in an accumulator.

Signed numbers

2.3 · Signed Number Representations

Signed numbers need an encoding for negative values. Three historical schemes are sign-magnitude, one’s complement, and two’s complement. Positive values generally share the same binary encoding; negative values differ.

Sign-magnitude stores a sign bit and magnitude. One’s complement flips every bit for a negative value. Two’s complement flips bits and adds one, supporting a unique zero and straightforward addition in finite-width hardware.

Bit width is not optional in signed arithmetic: the same bit pattern can represent different quantities under different signed conventions.

2.3.1 · Two’s Complement Representation

For an n-bit signed two’s complement word, representable values run from −2ⁿ⁻¹ to +2ⁿ⁻¹ − 1. The most significant bit is 1 for negative values and 0 for nonnegative values.

To encode a negative value, write the positive magnitude in n bits, complement every bit, then add one modulo 2ⁿ.

2.3.2 · Two’s Complement Arithmetic

Add n-bit operands just as unsigned bit strings and retain only the low n bits. Interpret the resulting word as a signed value. Subtraction computes A + (two’s complement of B).

One’s complement represents a negative value by inverting each bit of its positive n-bit magnitude. In an eight-bit word, +7 is 00000111 and −7 is 11111000.
