4.1 · Logic gates

What is a logic gate?

UNIT 04 · DIGITAL ELECTRONICS

Logic becomes hardware

Explore logic functions through connected symbols, truth tables, waveforms, circuit implementations, and HDL examples.

ANDORNOTXOR

A digital logic gate maps one or more logical inputs to a binary output according to an exact Boolean rule. A truth table lists every permitted input combination and the corresponding result.

Logic gates are assembled to form combinational functions, arithmetic circuits, control blocks and many other hardware structures. A gate symbol describes its logic behavior, not necessarily the transistor implementation.

Logical versus electrical levels

Logic zero and logic one represent two accepted signal ranges. They are not required to be exact voltages.

In circuit design

In CMOS and TTL, the electrical limits for a valid LOW or HIGH depend on the device family and supply conditions.

Positive and negative logic conventions

Positive logic interprets the higher nominal voltage level as logic 1 and the lower level as logic 0. Negative logic reverses that interpretation without changing the physical voltage.

4.2 · Logic gates

AND gate · All inputs must be HIGH

A two-input AND operation produces logic 1 only for A = 1 and B = 1. Adding more inputs extends the same rule: the output is HIGH only when every input is HIGH.

AND gates are useful for qualification and enable logic. A data signal can pass when an enable control is asserted.

Boolean form

Y = A · B. With three inputs Y = A · B · C.

In circuit design

Combine an event and an enable: Y = event · enable.

RELATED TOPIC · AND HARDWARE

AND gate using diodes and transistors

Diode logic can realize the AND truth table by combining a pull-up resistor with input clamp diodes. In the idealized operation, any LOW input clamps the output LOW; all HIGH inputs allow the output to rise.

Transistor-based implementations may cascade stages or use an inverted network followed by another inversion. Circuit-level behavior also depends on noise margins, loading and voltage drops.

Diode AND principle

Pull-up resistor sets the output HIGH when none of the input diodes clamps it.

4.3 · Logic gates

OR gate · Any asserted input is sufficient

An OR gate produces a HIGH output when at least one of its inputs is HIGH. The output is LOW only when all inputs are LOW.

The OR is inclusive: when both A and B are 1, Y is still 1. The Boolean addition symbol denotes OR, not integer addition.

Y = A + B. For three inputs Y = A + B + C.

RELATED TOPIC · OR HARDWARE

OR gate using diode and transistor logic

A diode OR arrangement drives a common output when any input becomes HIGH; a resistor establishes a LOW level when none is asserted.

Real diodes introduce a forward voltage drop, so their output levels must be checked against the input thresholds of the next stage. Transistor logic uses active devices and bias networks instead.

Practical limits

Forward voltage, resistor choice, fan-out and input noise margin constrain a discrete-diode implementation. CMOS gates use complementary transistor networks for full-rail outputs.

4.4 · Logic gates

NOT gate · Logic inversion

A NOT gate has one input. It reverses the binary value: an input of 0 produces 1, and an input of 1 produces 0.

An inversion bubble on a logic symbol denotes the complemented signal. An inverter may be built from a transistor and load or a complementary PMOS/NMOS pair.

RELATED TOPIC · RTL INVERTER

Discrete inverter operation

A resistor-transistor inverter can produce a HIGH output when its transistor is OFF. When the transistor turns ON, it pulls the output toward the LOW rail.

The output has opposite logical polarity to the input. A CMOS inverter uses a PMOS pull-up and NMOS pull-down: ideally only one is conducting in a stable state.

4.5 · Logic gates

Why NAND and NOR are universal

AND, OR and NOT can all be constructed using only NAND gates or only NOR gates. A set of gates capable of expressing every Boolean function is called functionally complete.

This matters in cell libraries, where it can be useful to implement an entire logic network using a small selection of transistor structures, while still meeting timing and power constraints.

Single-family construction

A NAND fed with the same signal at both inputs inverts it; a NOR with tied inputs does likewise.

In circuit design

Any combinational Boolean function can be mapped into NAND-only or NOR-only gates.

RELATED TOPIC · NAND

NAND gate · Complemented AND

NAND performs an AND operation and then inverts it. Consequently, its output becomes 0 only when every input is 1.

The output inversion bubble is essential: NAND and AND have the same body shape but opposite output polarities.

4.5.1 · Logic gates

NAND-only inverter, AND and OR networks

A NAND with its two inputs tied together gives ¬A. Another NAND applied to the inverted result can restore A · B. Inverting both operands and NANDing them produces A + B.

Although these identities are logically equivalent, each physical gate adds delay, capacitance and power cost. Technology mapping chooses structures based on circuit requirements.

RELATED TOPIC · NOR

NOR gate · Complemented OR

NOR first performs an OR operation, then inverts it. Its output is 1 only if all inputs are 0.

Applying the same signal to both NOR inputs creates a NOT operation. De Morgan’s laws explain how NOR can build the other fundamental functions.

RELATED TOPIC · NOR APPS

NOR-only logic constructions

Tying the inputs of a NOR gate gives the NOT function. Two NOR stages can produce OR. To form AND, invert A and B separately using NORs, then NOR those inverted signals.

A Boolean identity does not guarantee identical analog behavior: gate count, fan-out, and propagation delay can differ.

4.6 · Logic gates

XOR gate · Detect unequal inputs

An XOR gate is HIGH when its two inputs differ. It is the Boolean modulo-two sum, where 1 ⊕ 1 = 0.

XOR is fundamental for binary adders, parity networks, code transforms and mismatch detection. A chain of XOR operations produces an odd-parity function.

RELATED TOPIC · XOR INVERTER

XOR as a controlled inverter

For a single input A, A ⊕ 0 equals A, while A ⊕ 1 equals ¬A. Therefore a second input can select whether a signal passes unchanged or inverted.

This behavior is used for adder/subtractor control: an XOR can conditionally invert an operand when subtraction is selected.

RELATED TOPIC · XOR PROPERTIES

Important properties of XOR

The XOR result depends on parity rather than the order of operands. A ⊕ A = 0, A ⊕ 0 = A and A ⊕ 1 = ¬A.

XOR is associative and commutative, enabling parity-tree reduction and Gray-code transforms. Real gate networks still exhibit finite propagation delay.

4.8 · Logic gates

XNOR gate · Detect equal inputs

XNOR is the complement of XOR. Its output is HIGH for matching two-bit inputs, 00 or 11, and LOW for mismatches, 01 or 10.

XNOR is especially useful in magnitude/equality comparators, where corresponding bit pairs are compared before their match signals are combined.

RELATED TOPIC · XNOR INVERTER

XNOR as an equality detector and inverter

An XNOR gate with one input tied LOW inverts the other input, whereas tying that input HIGH passes the other input unchanged.

A multi-bit equality comparator XNORs each corresponding bit pair and ANDs the matching results together.

4.9 · Logic gates

Enable and inhibit logic

A second input can act as a control signal that permits or suppresses a data signal. AND follows input A when B = 1, while OR follows A when B = 0.

The complemented versions NAND and NOR can also enable or inhibit a signal, but their enabled output is inverted. The disabled output is a constant 0 or 1 determined by the gate.

4.2–4.10 · Logic gates

Three-input gates and parity

AND and OR support multiple inputs naturally. A three-input XOR parity network can be formed by cascading two XOR operations: (A ⊕ B) ⊕ C.

The resulting parity output is HIGH when an odd number of the three inputs is asserted.

RELATED TOPIC · LOGIC DESIGN

Two-bit equality comparator design

Two unsigned binary words are equal when every pair of corresponding bits matches. Individual XNOR gates generate per-bit equality signals, which are then combined using AND.

For two-bit values A₁A₀ and B₁B₀: EQ = (A₁ XNOR B₁) · (A₀ XNOR B₀). This structure scales to wider comparators by reducing the per-bit match signals.

Verilog gate models and NAND networks

Continuous assignments in Verilog describe simple combinational expressions. The synthesis result should preserve logical behavior, while a gate-level netlist depends on the target library.

Use simulation to verify input cases and make sure widths and active-high/active-low signals are documented.

VHDL logic gates and structural mapping

VHDL concurrent signal assignments describe combinational logic, and the IEEE std_logic_1164 package provides useful resolved logic types.

Structural descriptions instantiate submodules to form a hierarchy. Synthesis tools may optimize the hierarchy while maintaining function.
