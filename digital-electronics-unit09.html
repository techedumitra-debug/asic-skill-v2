UNIT 09 · LESSON 00 · THRESHOLD LOGIC

Threshold logic: a weighted decision

Unlike a fixed AND or OR function, a threshold gate combines its binary inputs using numerical weights and compares the total with a programmable threshold.

Binary inputs→Weighted sum→Compare with T→F ∈ {0,1}
Technical interpretation

This chapter introduces a gate whose behavior can change when its weights or decision boundary change. Practice each rule with the circuit to see how the same symbol can represent several switching functions.

RELATED TOPIC · CONVENTIONAL VERSUS THRESHOLD

Conventional gates and threshold gates

AND, OR and NOT apply fixed Boolean operations. A threshold element instead makes a yes/no decision about a weighted arithmetic sum.

Fixed gate

Logical rule: AND, OR or inversion. Connection topology determines behavior.

Threshold element

Rule: Σwᵢxᵢ ≥ T. Weights and threshold determine behavior.

Technical interpretation

One threshold element can sometimes replace several levels of basic logic. The number of gates alone does not establish power, area or speed; physical implementations must also be considered.

RELATED TOPIC · DECISION RULE

The threshold inequality

The output is HIGH when Σ(wᵢxᵢ) ≥ T; otherwise the output is LOW. Equality counts as HIGH.

Technical interpretation

For inputs x₁…x₃, compute W = w₁x₁ + w₂x₂ + w₃x₃, then compare W with T. This is ordinary arithmetic followed by a Boolean decision.

Why negative weights matter

A negative weight subtracts from the total when its input is asserted. This can inhibit an otherwise active result.

Negative weights allow a single device to express nonmonotonic input effects. For example, raising x₁ from 0 to 1 can force F from 1 to 0.

UNIT 09 · LESSON 12 · THRESHOLD LOGIC

NULL and always-HIGH functions

If T is greater than every possible weighted sum, F is always 0. If T is at or below every sum, F is always 1.

UNIT 09 · LESSON 20 · THRESHOLD LOGIC

Why XOR is not one threshold gate

XOR is HIGH on 01 and 10 but LOW on 00 and 11. One linear weighted comparison cannot separate those four points.

Two-stage XOR networkTWO THRESHOLD ELEMENTS

Technical interpretation

If w₁≥T and w₂≥T are required, then w₁+w₂≥2T. But output 11 must be LOW, requiring w₁+w₂<T, while 00 LOW requires T>0. The requirements contradict each other.

UNIT 09 · LESSON 28 · THRESHOLD LOGIC

What does unate mean?

A function is unate in x if, with other inputs fixed, increasing x never sometimes raises the output and sometimes lowers it.

Unateness explorerINPUT MONOTONICITY
Technical interpretation

A positive unate variable can only increase or preserve F; a negative unate variable can only decrease or preserve F.
