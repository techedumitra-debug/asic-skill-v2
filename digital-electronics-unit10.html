Flip-flops and the memory of digital circuits

Technical explanation

This unit develops storage circuits from cross-coupled logic through clocked storage, master–slave operation, and practical timing constraints.

RELATED TOPIC · COMBINATIONAL SEQUENTIAL

Combinational versus sequential behavior

A combinational output is determined by the current input alone; a sequential output also depends on a remembered state.

Combinational

Current input → current output

Example: XOR, adder

Sequential

Current input + state → next state

Example: register, counter

Technical explanation

An adder calculates continuously from its input bits, while a register holds its previous output until a permitted update.

RELATED TOPIC · SEQUENTIAL ARCHITECTURE

Inputs→Next-state logic→State register↺State feedback

A clock or asynchronous event controls when the stored state changes.

Technical explanation

This feedback path is what distinguishes an ordinary logic network from a state machine.

UNIT 10 · LESSON 03 · FLIP-FLOPS

Synchronous and asynchronous sequential circuits

A synchronous storage element uses clock timing to coordinate state changes. An asynchronous circuit can react to input or internal events without a shared clock.

Combinational

Current input → current output

Example: XOR, adder

Sequential

Current input + state → next state

Example: register, counter

Technical explanation

A flip-flop with an asynchronous reset is still a clocked storage element: its reset is an asynchronous control, not a fully asynchronous architecture.

UNIT 10 · LESSON 33 · FLIP-FLOPS

Master–slave storage stages

A master latch and slave latch operate on complementary clock phases so that data cannot pass freely through both stages at once.

Technical explanation

The master is transparent during its designated phase; the slave updates in the opposite phase. This prevents the repeated toggling associated with the naive level-enabled JK structure.
