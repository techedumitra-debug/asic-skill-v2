RELATED TOPIC · SCHMITT PRINCIPLE

Schmitt trigger: two switching thresholds

A Schmitt trigger uses different input limits for rising and falling input voltage. The gap between these limits is hysteresis. It prevents small disturbances near the switching threshold from causing repeated output transitions.

Schmitt trigger: two switching thresholdsLIVE EXAMPLE

Technical interpretation

For an inverting Schmitt trigger, the output changes to LOW when the input rises past the upper limit, and returns HIGH only after the input falls below the lower limit.

Worked example
