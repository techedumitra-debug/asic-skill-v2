AUTOMATED QUALITY GATES
Pre-stage and post-stage sanity

          In-browser only · no downloads
        

        
Every real stage verifies input design configuration and prerequisite OpenDB files before execution, then validates the generated OpenDB and expected timing files. These are implementation integrity checks, not a substitute for signoff STA, extraction, DRC, LVS or EM/IR.

        
Start a session and run a stage to view its checks.

        

          
Finalization versus signoff

          
Integrated: ORFS reports, OpenDB observations, and GDSII/DEF/netlist/SDC presence checks. Files stay in the isolated container.

          
Not included: foundry-qualified signoff DRC/LVS, extracted-corner signoff STA, EM/IR, IR drop or reliability certification. These must be completed in appropriate qualified tools before tapeout.
